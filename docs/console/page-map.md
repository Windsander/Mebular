# 控制台页面地图（哪个设置在哪个 Tab）

## 首次上手（引导态：建新 / 加入）

家目录**真正为空**（无 `config.json`、无 `user-master-key.json`、无 `<storagePath>.identity.json`）时，`mebular serve` **不自举 root**，而是进入**引导态**：只服务 `/healthz` + `/console` 引导页 + `/app/provision/*`（其余 admin API 一律 `409 provision_required`），且**仅 loopback**。

引导页两个入口（全程 GUI，不需要命令行）：

| 入口 | 动作 | 结果 |
|---|---|---|
| **建新忆云** | `POST /app/provision/create`（设备名可改；填名字即可，带 `device-` 前缀也不会重复拼接——见「设备名归一化」） | 生成 root 主密钥 + 写 `config.json`（`joinService.enabled=true`、`mcp.http` 回环、`network` 默认）→ **自动重启** → 正常态（「＋ 邀请设备」可用） |
| **加入已有忆云** | `POST /app/provision/join`（粘贴邀请令牌；复用 fleet 令牌验签/兑换） | 取回**委派证书链**（delegated，**无主私钥**）+ 主公钥（仅公钥）+ inviter hints 入 `<home>/net/peers.json` → **自动重启** → 正常态（授权分区 = 令牌分区） |

错误可读：令牌过期 / 签名不符 / 端点不可达 / 已使用 → 页面直接显示原因；重复调 provision → `409`；失败**不残留半成品**（仍可重试）。未以服务方式运行时给出手动重启命令（`nohup mebular serve …`）。

**设备名归一化（F-ONB-1）**：设备名先 sanitize，再去掉**所有重复的 `device-` 前缀**，最后拼一次前缀 —— 输入 `TestB` / `device-TestB` / `device-device-TestB` 都得到 `device-TestB`；空名 → `device-local`。两个输入框带「将使用 deviceId: …」实时预览。

设置弹层分五个 Tab：**常用**（默认开，只读状态 + 重启向导 + 忆云卡）· **安全**（安全等级 / 动态码种子 / 恢复码三段）· **AI 助手** · **MCP 接入**（连接 / TLS 两组 + 危险与自救）· **高级**（常驻服务 / 网络 / 自动化三组 + 底部「诊断与恢复」折叠）；只读信息统一在**「关于本机」**面板（点顶栏状态徽章 `本机 · <deviceId>` 打开）。

**U-1 折叠预算（≤5，当前 4）**：设置内只允许 `MCP 接入 · 危险与自救`、`诊断与恢复`（含 raw config / 手动连接 / 恢复指引）；关于本机只保留一个 `运行状态（只读）`；邀请面板一个 `邀请设备 · 详情`。字段帮助/风险改内联一行，不再有逐字段/逐卡「详情」「这是什么」或页级「改动如何生效」「高级项说明」。白名单单一真源：`IA_SETTINGS_FOLDS`。

**动作归属（U-1）**：全局动作只在全局位置——邀请设备只在顶栏 `#invite-device`；共享页空态只保留「＋ 新建记忆域」。设置页只保留只能在此处完成的动作（重启向导、忆云切换/改名、安全操作）与配置/状态。
IA 单一真源在 [`packages/console/settings-ia.js`](../../packages/console/settings-ia.js)，E1（`verify-console.mjs`）以迁移表驱动断言「不丢项：每项有且仅有唯一去处」。

**术语**：用户可见文案中表示本机所处共享网络的「网络 / Mebular」统一为「**忆云**」；产品名「Mebular 控制台」不变，「记忆域 / 记忆」不变。

E1 前后对比截图：[`screens/e1/`](screens/e1/)。U-1 设置/共享页收口前后对比：[`screens/u1/`](screens/u1/)。U-3 设置页设计收口（安全 / MCP / 高级）前后对比：[`screens/u3/`](screens/u3/)。

**顶栏（E1/E2-A2）**：品牌后是当前**忆云**徽章（名字只取 `overview.cloud.name`；旧守护没有该字段时隐藏，绝不按端口/目录猜）。操作为对称的「加入忆云」（次要）与「邀请设备」（主），窄屏折叠为图标；「连接已有地址」已撤下——它实际是**网内传输修复**，入口移到「高级 → 诊断与恢复 → 手动连接已知设备…」与设备卡「连不上？手动连接…」（不改变入网信任、不签发授权）。

**忆云（E2-A2）**：

- **加入忆云**：令牌 + 名字（预填「忆云 N」）+ 根指纹预览（`POST /admin/api/clouds/inspect`，只解码、不消费 nonce）；提交 `POST /admin/api/clouds/join {token,name,confirm:true}`。成功后 `current` 仍是旧值；桌面壳调 `window.mebularDesktop.cloudSwitch(id)`，Web-only 显示 `mebular cloud use <id>` + 复制。重复加入（409 `CLOUD_ALREADY_JOINED`）显示已有忆云与切换入口；令牌/确认/写入/端点/禁用等错误均有可读文案，且当前忆云不变。
- **忆云卡（设置 · 常用）**：位于只读状态/动作行之后。每行名字、[当前]/[已归档]、根指纹、最近使用、[切换]/[改名]；当前项不可切换，已归档切换需危险确认；改名写 `POST /admin/api/clouds/rename` 即时生效、不重启；**不提供删除**，文案固定「归档保留，不删除」。
- **深链**：`?view=settings&focus=clouds` 打开设置 · 常用并滚到忆云卡（托盘「管理忆云…」同款落点）。

**弹层交互（全局共用）**：

- **点空白**（backdrop `target === currentTarget`）与 **Esc** 关闭**最上层**弹层；一处实现全弹层受益。
- 危险语义：确认弹层的 Esc / 点空白 = **取消**（resolve false，永不等于确认）；首次上手（建新/加入）不可关闭；手动连接向导在「连接中」不可关闭。
- 背板固定不滚（`.modal { overflow: hidden }`）；滚动收进 `.modal-box`（`max-height: calc(100vh - 48px); overflow-y: auto`），所有弹层一致。
- 对齐：小弹窗加 `.modal-center` 垂直居中（邀请 / 切换忆云 / 安全操作 / 手动连接 / handoff / 通用确认 / 令牌输入 / 新建域）；大面板保持顶部对齐 + 内部滚动（设置 / 关于本机 / 加入忆云 / 首启引导）。

**呈现分级（轮 C）**：常显 = 名称 + 控件 + 状态（三元组相等时收成一行「生效中」）；帮助 / 机制解释 / 警告墙收进「详情」折叠；**异常自动出现**（已配置≠实际、未生效原因、待重启）。**安全卡（S3）**独占「安全」Tab 的 `#settings-security-slot`：三档状态 + 升级/降级、动态码种子、恢复码、待批准、拒绝原因；卡尾低权重「降级…」。

## 共享（只管理记忆域）

职责：域目录、新建域、订阅/退订、参与设备、退出并交接。邀请设备不在共享页出现（全局入口 = 顶栏 `#invite-device`）。

- 空态：只保留「＋ 新建记忆域」；文案「还没有记忆域。只有本机也可以新建一个记忆域并开始记录。」不再放邀请按钮或诊断指路。
- 新建域：写域公告 + 默认自订阅 `active:true` + 选中 + toast；0 条 / 0 对端也可写。
- 列表：每个域显示条数与订阅状态（已订阅 / 未订阅），右栏显示参与设备与退出并交接。

## 常用（只读状态 + 专属动作）

E1 三卡迁出后，常用不再承载可编辑字段，也不再重复全局邀请入口：

- 常驻运行状态（`#settings-resident`：守护/临时/未运行 + 对应动作）。
- 重启向导（桌面壳内可用；重新走首次设置，不动已有配置）。
- 只读状态：P2P、邀请服务、安全等级。
- 忆云卡（切换 / 改名；只能在设置内完成）。
- 邀请设备只在顶栏 `#invite-device`；共享页空态只保留「＋ 新建记忆域」。
- 其余可编辑配置在「高级」与「MCP 接入」；安全动作在「安全」。

## 安全（S3 · 独立 Tab）

三段式（U-3）：**安全等级**（当前档 + 三行档位 + 就地升级/降级 + 一段短边界）· **动态码种子** · **恢复码**。待批准与拒绝记录作为紧凑状态行收在「安全等级」内；内部错误码（如 `totp_not_configured`）不出现在主界面。

| 档 | 一行说明 | 改道 |
|---|---|---|
| **低（默认）** | 无额外门槛。 | 邀请 / 移出维持现状；移出留在「更多操作」折叠内 |
| **中 · 动态码** | 6 位动态码，防顺手。 | 邀请先输码；移出提级为一等危险动作、输码后执行 |
| **高 · 设备会签** | 另一台设备核对配对号，防伪造；只对之后的动作生效。 | 邀请/移出先出配对号并等待批准，批准后自动出令牌/执行；降级也要会签 |

- 边界（安全等级段尾一行）：中档挡手不挡钥匙（设备被拿走，种子也一并被拿走）；高档需要另一台设备在场，不在时用离线恢复码。
- 动态码种子：显示 fingerprint；导入走分组文本/otpauth；显示种子前必须再输一次本机码（root 可生成共享种子）。种子不进事件/日志/同步。全部设备丢失种子时由 root 重置；无主密钥备份则不可恢复。
- 恢复码：升到高档时强制生成并一次性展示（须回执「我已抄写」）；安全卡显示 keyId 前 8 与最近使用；「轮换恢复码」用旧码换新码，新码同样只显示一次。
- 待批准入口在安全卡顶部 + 星图「需要注意」；批准按钮文案「配对号一致，批准」，拒绝即时写入。拒绝原因以人话列在卡内（不显示事件 ID），审计保留完整记录。移出后在设备卡与审计显示状态「已移出」。
- 顶栏只读徽章 `🛡 安全：低/中/高`（点击 = 打开「安全」Tab）；桌面托盘同样有一行只读「安全等级」，点击只打开控制台，不做壳内写操作。
- 前后对比截图（活体 / mock / 窄屏 / 审计）：[`screens/security-tiers/`](screens/security-tiers/)；U-3 收口：[`screens/u3/`](screens/u3/)。

## MCP 接入（独立 Tab，危险项）

U-3 收成两组：**连接**（`mcp.http.port` · `mcp.http.auth` · `mcp.http.host`）与 **TLS**（`mcp.http.tls` · `mcp.http.tlsCert` · `mcp.http.tlsKey`）。改端口/认证/监听/TLS 会立即影响控制台自身访问方式；字段帮助内联一行，唯一的 `MCP 接入 · 危险与自救` 折叠保留后果与两条恢复路径（bearer 粘贴 token 自救；oauth/端口失联改回 `config.json` 并重启）。bearer 模式首次 401 时用 App 内「输入访问令牌」弹层（Electron 不支持 `window.prompt`）。命中自锁项时关键警告会进入二次确认弹层。

**邀请面板（E1 单屏 + C7 扫码即通 + E2-A2 本忆云行）**：打开即见**令牌 + 二维码 + 复制**（二维码内容=令牌文本，服务端渲染 SVG，可选依赖缺省时降级为文本提示）与「本忆云：<名字> · 根指纹 sha256:…」（取 `overview.cloud`，供加入方核对），必要安全提示一行；join 端点、`fleet join` 命令、兑换语义（作用域=令牌记忆域，默认 24h 到期自动撤销）、重新生成全部收「详情」。若加入服务未启用：弹层内「一键启用并继续」——走既有配置写路径、提示将重启守护，恢复后自动签发令牌（不再指路「设置 → 常用」）。

## 高级（常驻服务 / 网络 / 自动化 + 诊断）

| 分组 | 字段 |
|---|---|
| 常驻服务 | `joinService.enabled` · `joinService.bind` · `joinService.port` |
| 网络 | `network.enabled` · `network.libp2p.listen` |
| 自动化 | `sync.antiEntropy.enabled`（自动对账） · `semantic.enabled`（语义召回） |

> **U-3 版式**：每组 = 标题 + 一行说明 + 字段行；字段帮助内联一行（绑定地址/端口的详细解释压成一行）。不再有独立「连接排障 / 版本 / 完整配置 / 应用结果 / 恢复指引」主卡，统一收进底部「诊断与恢复」折叠。主区文本 ≤1200 字（不含折叠）。

> **U-1 专家面**：`sync.peerWhitelist` 为 config-only（GUI 不渲染，键与后端保留）；`sync.policyIssuers` / `autoGrant` / `status.invite.grantTtl` 已从 GUI 删除；不再有任何「引导签发者」输入或只读行。

> **暴露面收敛（B + 轮 C）**：反熵间隔/抖动、快照阈值、召回阈值属自动策略 → `internal`（GUI 不渲染，需手工编辑 `config.json`）；`network.libp2p.relayServers` 为只读（自动 relay 池 = config seeds ∪ 令牌 hints ∪ 地址簿学习，见「关于本机 · 只读状态」）；`network.libp2p.relayUnlimited` 转为 internal。字段元数据由服务端单一真源 `packages/mcp/src/config-schema.mjs` 驱动（`/admin/api/settings.configSchema`），控制台不再重复声明。

## 诊断与恢复（高级 Tab 底部只读折叠）

U-3 顺序：**版本与服务状态** · **完整配置** · **最近一次应用结果** · **手动连接** · **恢复指引**。折叠内用紧凑小标题分段，不再是五张主卡。

- **版本与服务状态**：`/healthz` 的 name/version/status、MCP 监听、TLS、控制台写入开关、P2P、状态指纹。
- **完整配置**：`config.json` 原文（复制 / 下载）。
- **最近一次应用结果**：状态（已生效 / 重启中 / 未按预期生效 / 已回滚）、时间、字段清单、原因、备份路径、逐项校验。
- **手动连接**：一台已加入同一忆云的设备一直未连接时，手动粘贴对方 multiaddr 建立传输；只修复连接，不改变入网信任与订阅。设备卡离线时也有同款入口。
- **恢复指引**：auth 误切 · host 误设 · 缺证书 · 控制台打不开（含 `MCP_INSECURE_CONFIG` / `MCP_STORAGE_LOCKED` 判读；OAuth 缺 `MEBULAR_OAUTH_ADMIN_SECRET` / `MEBULAR_OAUTH_REGISTER_SECRET` 时只能改回配置）。

## 关于本机（顶栏徽章入口，只读）

只讲四件事：**身份与存储**（含 `config.json` 路径 + `.bak`，写盘路径从常页面收编到此）· **收敛健康** · **运行状态**（唯一折叠，含同步节奏真值、自动推导状态、地址广播、NAT、join、TLS、对端连接路径、舰队摘要、能力清单）。不再重复任何编辑项，也没有「引导签发者」段。

> 星图设备卡同样有一行只读「当前路径」（`direct`/`lan`/`relay` + 地址 + 起始时间；未连接时显示 `lastError`）。数据来自 core 候选地址簿（`settings.peers.paths`），只展示不改变授权。

> **同步节奏**（`sync.autoSync` / `sync.pushOnWrite`）已从 GUI 编辑面移除——默认常开、不建议关闭；需要改动请手工编辑 `config.json`。该处只读展示「已配置 vs 实际」双值。
>
> 所有可运行时项（host/port/auth/tls、listen/relay、semantic、join 等）在编辑面给**三元组**「已配置 X / 实际 Y / 未生效原因」，原因由服务端计算（`/admin/api/settings.effective`）。

## CSRF 403 自愈（U-1）

长开页面（CSRF cookie 12h）或守护重启后，旧 token 可能让写操作返回 `403 CSRF token 缺失或无效`。`api()` 捕获该文案后：重取一次 `/console/`（响应头 `x-mebular-csrf` + cookie）→ **保留当前表单内容** 原样重试一次；仍失败给「会话已刷新，请重试；仍失败请重开窗口」。不整页重载、不做无限重试。断言覆盖：旧 token → 自动恢复一次成功；重取 1 次、写重试 1 次、页面无重载。

## 改动即生效（无「保存 / 撤销」按钮）

「高级」与「MCP 接入」的字段**改动即写入**（勾选/选择立即、文本/数字失焦即写；写入前仍会做 host/auth/tls 组合校验）；保存按钮已从用户路径消失。

**生效（G）**：

- 改动含需重启项 → 写入后**自动重启**（服务托管时）并轮询等待恢复，或给出前台手动命令；全为即时（热路径）项 → 就地生效，不重启。
- 恢复后显示 **绿色「已生效（字段清单）」**（逐字段生效校验通过）或 **红色「未按预期生效」/「已回滚」**。
- **自锁防护**：改动命中 `mcp.http.auth` / `mcp.http.host` / `mcp.http.tls` 时先品牌确认卡二次确认（重启后控制台可能不可达；失联请手工编辑 `config.json` 改回），未确认则返回 `needsConfirmation` 且不写盘、不重启。
- **回滚兜底**：新配置启动失败（如 join 端口被占）→ 自动用 `config.json.bak` 回滚并重启旧实例；原因写入诊断折叠「最近一次应用结果」。
- 未以服务方式运行（前台 nohup）→ 返回手动命令 + 备份路径（待重启横幅保留，可「一键重启」或复制命令）。
