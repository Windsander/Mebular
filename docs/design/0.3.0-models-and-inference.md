# 0.3.0 模型供应与 Inference（sidecar 内置）

> 状态：C8 命名与边界冻结稿。
> 范围：沉浸式 Memory Runtime 的本地/远程模型供应；不改变 0.2 轻量 MCP 路径。
> 相关：[Inference API](./0.3.0-inference-api.md) · [精选模型目录](./0.3.0-model-catalog.md)

---

## 0. 一页结论

1. **模型供应属于 Memory Runtime sidecar**，不是独立 daemon，也不在 MCP 进程里执行模型。
2. **models 管供应，inference 管执行。**
   - `ModelCatalog` / `ModelInstaller` / `ModelSelector`：目录、manifest、下载、校验、安装、卸载、选择。
   - `InferenceProvider` / `InferenceEngine`：加载模型、执行推理、返回结果。
3. **`InferenceProcess` 只是 managed-child engine 的受管子进程**，不是 service。
   - 只有 sidecar 能启动/停止；
   - 无公开 API、独立 token、独立安装或独立配置；
   - 不承载记忆、不写图、不参与同步。
4. **不是所有模型都需要子进程。** Ollama 是 external daemon，远程 API 是 remote，heuristic 是 in-process；只有 llama.cpp 这类本地 native engine 需要 `InferenceProcess`。
5. **用户只选择模型来源和模型包**；下载、校验、引擎准备、启动、健康检查、失败回退全部自动。
6. **轻量 MCP 模式没有 sidecar，也就没有 models/inference**；现有用户不强制迁移。

## 1. 命名冻结

| 层 | 名字 | 职责 |
|---|---|---|
| 模型管理 | `ModelCatalog` | 精选模型目录、pack 元数据、硬件要求 |
| 模型安装 | `ModelInstaller` | 下载、续传、校验、安装、卸载、进度 |
| 模型选择 | `ModelSelector` | 硬件推荐、当前选择、激活/停用 |
| 推理执行 | `InferenceProvider` | 记忆层调用的 extract / summarize / planQuery |
| 引擎适配 | `InferenceEngine` | llama.cpp / Ollama / MLX / remote 的统一接口 |
| 推理进程 | `InferenceProcess` | 本地 native engine 的受管子进程 |
| 进程实现 | `llama.cpp inference process` | 上游二进制名是 `llama-server`，架构层不称 service |

禁止使用：

- `LLAMA service`；
- `model-runtime daemon`；
- 按模型拆分的 `qwen-service` / `llama-service`；
- 把 `InferenceProcess` 描述成独立服务或第二套运行时。

## 2. 结构

```text
Memory Runtime sidecar
  ├─ memory orchestration
  │    ingest / recall / context / checkpoint / compact
  └─ models
       ├─ ModelCatalog
       ├─ ModelInstaller
       ├─ ModelSelector
       └─ inference
            ├─ InferenceProvider
            │    heuristic / local / host / api
            ├─ InferenceEngine adapters
            │    ├─ LlamaCppInference   → managed-child
            │    ├─ OllamaInference     → external-daemon
            │    ├─ RemoteInference     → remote
            │    └─ MlxInference        → managed-worker（未来）
            └─ InferenceProcess
                 仅 managed-child engine 使用
```

记忆层只依赖 `InferenceProvider`，不知道底层是规则、本地进程、Ollama 还是远程 API。

## 3. Engine lifecycle

| Engine | lifecycle | 是否起子进程 | 说明 |
|---|---|---|---|
| llama.cpp（Qwen3 GGUF） | `managed-child` | 是 | sidecar 启动/停止 `llama-server`，loopback + 随机 token |
| Ollama | `external-daemon` | 否 | 用户/系统已有 daemon，sidecar 只 attach |
| LM Studio / vLLM | `remote` | 否 | OpenAI-compatible endpoint |
| 远程 API | `remote` | 否 | 纯 HTTP |
| MLX | `managed-worker` | 可能是 | 未来；取决于 Python worker 或 in-process |
| heuristic | `in-process` | 否 | 规则，无模型、无进程 |
| host-provided | `host` | 否 | 宿主提供，sidecar 不启动进程 |

`InferenceProcess` 是 **sidecar 私有的受管子进程**，不是 service：

- 只有 `LlamaCppInferenceEngine`/`InferenceService` 能启动/停止，最多一个实例；
- 无公开 API、独立 token、独立安装或独立配置；不承载记忆、不写图、不参与同步；
- `LlamaCppInferenceEngine` 是 llama.cpp adapter，不按模型拆服务；
- `inference-provider` 只能通过注入 facade 获取连接，不能自行创建多份进程。

`InferenceProcess` 的生命周期：

```text
idle → starting → ready → busy → idle → stopped
                    ↘ crashed → backoff → starting
```

- 懒启动：`model.source=local` 且首次推理时才启动；
- 空闲停止：默认 15 分钟无请求停止进程，释放内存；模型文件保留；
- 崩溃回退：进程崩溃不拖垮 sidecar，回退 heuristic，按退避重启；
- 切换模型：停旧进程，启新进程；不重启 sidecar。

## 5. 安装流程

```text
用户选择 Qwen3 8B
  → 平台/架构检查
  → 内存/磁盘检查
  → 解析内置 manifest
  → 下载模型（Range 续传、进度、速度、ETA、可取消）
  → sha256 校验
  → 安装到 <dataDir>/models/<packId>/
  → EngineInstaller.ensureInstalled()（官方 llama.cpp 资产）
  → 启动 InferenceProcess（binaryPath 来自 EngineInstaller）
  → /health
  → 激活为 local InferenceProvider
```

引擎资产与模型资产分开：

```text
EngineInstaller
  not_installed → downloading → verifying → extracting → installing
                                                         ├─► installed
                                                         └─► failed → 清理临时目录
  取消 → cancelled；失败/取消都不留下半安装目录
```

- 只解析内置 `engine-assets.ts` 官方清单；下载 URL 只能由
  `llamaCppReleaseAssetUrl()` 推导，不接受任意 URL。
- 下载到 `<dataDir>/inference/engine/.partial-*`，校验 `sizeBytes` + sha256。
- 解压前列出所有条目，拒绝绝对路径、`..`、空段、盘符、反斜杠、符号链接/硬链接；
  解压到临时目录，确认 `binaryPath` 为普通文件后原子 rename 到 `<engine>/current`。
- POSIX `chmod 0755`；Windows 保留 `.exe`。
- 状态文件 `<dataDir>/inference/engine/state.json`（0600、原子写）：
  `release/platform/arch/asset/sha256/binaryReady/installedAt/verifiedAt`；公开视图不含绝对路径。
- `ensureInstalled()` 幂等；`activate` / `startEngine` 前必须成功，未安装/未校验不能启动。
- 失败码：`engine_asset_unsupported` / `engine_not_installed` / `engine_download_failed` /
  `engine_http_error` / `engine_size_mismatch` / `engine_checksum_mismatch` /
  `engine_extract_failed` / `engine_binary_missing` / `engine_install_failed` /
  `engine_storage_unavailable` / `cancelled`。

失败时：

```text
下载失败 / 校验失败 / 内存不足 / 引擎启动失败
  → 明确错误码 + 重试
  → 保持 heuristic
  → 不阻塞对话
```

安装任务状态（`phase` 表示当前阶段）：

```text
phase=model:   downloading → verifying → installing（模型原子提交）
                                               │
phase=engine:                                  ▼
               installing（EngineInstaller） → completed
                                       ↘ failed（模型保留 + engine_* 错误）
                                       ↘ cancelled
                                       ↘ interrupted（sidecar 重启）
```

- `ModelInstallJob.phase` 为 `model | engine`；`progress` 是当前 phase 的进度。
- 引擎已安装且校验通过时跳过下载；模型已安装但引擎失败时，重试只补引擎，不重下模型。
- 单活动任务；第二个安装返回 `install_busy`。
- 任务状态持久化到 `<dataDir>/inference/install.json`（operational state）。
- sidecar 重启后标记 `interrupted`，允许重试；partial 文件由下载器续传。
- 取消必须 abort 下载；是否保留 partial 由策略决定，但不能留孤儿进程。

## 6. Sidecar API

所有端点沿用 sidecar host token / loopback / Origin 校验 / 统一信封。

### 模型与安装

```text
GET  /memory-runtime/v1/models
GET  /memory-runtime/v1/models/:packId
POST /memory-runtime/v1/models/:packId/install
GET  /memory-runtime/v1/installs/:jobId
POST /memory-runtime/v1/installs/:jobId/cancel
POST /memory-runtime/v1/models/:packId/verify
POST /memory-runtime/v1/models/:packId/activate
POST /memory-runtime/v1/models/:packId/deactivate
POST /memory-runtime/v1/models/:packId/remove
```

### Inference

```text
GET  /memory-runtime/v1/inference
POST /memory-runtime/v1/inference/settings
```

- `/models` 返回 catalog + installed + active + hardware + recommended；不泄漏 token、keyRef、内部路径。
- `/inference` 返回 config source、active source、engine、lifecycle、state、degraded、reason、warnings。
- `/inference/settings` 只接受 `{source: heuristic|host|api|auto}`；`local` 必须走
  `POST /models/:packId/activate`（缺 pack 返回 400 `pack_required`）。切换为进程内热切换，不重启 sidecar。
- 激活失败只回退 heuristic；不自动切换到第三方 provider。
- **激活/停用是进程内热切换，不重启 sidecar。**

## 7. Provider 与配置

```ts
type InferenceSource = 'heuristic' | 'local' | 'host' | 'api';

interface InferenceProvider {
  status(): Promise<InferenceStatus>;
  extractCandidates(request: ExtractionRequest): Promise<ExtractionResult>;
  summarize(request: SummaryRequest): Promise<SummaryResult>;
  planQuery(request: QueryPlanRequest): Promise<QueryPlanResult>;
  reconfigure(settings: InferenceSettings): Promise<void>;
  dispose(): Promise<void>;
}

interface InferenceEngine {
  readonly id: string;
  readonly lifecycle: InferenceLifecycle;
  prepare(model: ModelManifest): Promise<void>;
  start(model: ModelManifest): Promise<EngineEndpoint>;
  stop(): Promise<void>;
  health(): Promise<EngineHealth>;
  status(): EngineStatus;
}
```

配置键保持兼容：

```jsonc
{
  "model": {
    "source": "heuristic", // heuristic | local | host | api | auto
    "local": { "pack": null, "path": null, "threads": 4, "enginePath": null },
    "api": { "baseUrl": null, "model": null, "keyRef": null, "allowRemote": false }
  }
}
```

- 内部类型用 `InferenceSettings`，不把 `modelRuntime` 写进新代码。
- 模型选择按设备保存，不同步进忆云。
- API key 只走 `env:` / `file:` / `keychain:`，不写 config、不进日志、不进状态。

## 8. 安全

- 模型下载只接受精选仓库 + 固定 revision + 固定文件 + sha256；拒绝任意 URL。
- 引擎下载只接受 `engine-assets.ts` 官方 release URL；同样校验 size + sha256。
- 归档解压先列出条目再写入：拒绝绝对路径、`..`、空段、盘符、反斜杠、符号链接/硬链接；
  只允许预期 `archiveRoot` 下的普通文件/目录；解压到临时目录，成功后才原子提交。
- 失败/取消清理临时目录；崩溃后启动时清理 partial/extract，必要时恢复 backup。
- `InferenceProcess` 只监听 loopback，随机端口 + 随机 bearer token；token 不落日志/状态。
- 模型文件、安装任务、引擎状态是 operational state，不是记忆权威；不建第二套记忆库/同步。
- 远程 API 必须显式 `allowRemote=true`；失败不回退到其他外部 provider。
- 状态/错误不返回 prompt、模型响应体、密钥、keyRef、绝对路径。

## 9. 兼容

- 现有轻量 MCP 用户不变：不启动 sidecar、不建模型目录、不弹模型 UI。
- 沉浸式是用户显式选择；模型是沉浸式里的高级选择。
- 0.2 数据不改写；模型选择不进入忆云同步。
- 未来接 Ollama / MLX / 其他 provider 只加 `InferenceEngine` adapter，不新增 daemon。

## 10. 验收

- Qwen3 4B/8B/14B 目录、manifest、sha256、license 正确；
- 安装：进度、取消、续传、重启恢复、磁盘/内存失败；
- 激活：热切换、健康检查、失败回退 heuristic；
- 引擎：llama.cpp 启动/停止/空闲停止/崩溃退避；
- API：host token、loopback、无 token/路径泄漏；
- 真实 smoke：至少一个平台下载 Qwen3 4B/8B、启动 inference process、完成一次抽取/召回；
- 轻量模式零 sidecar/模型目录副作用；
- 现有 29 公共 MCP 工具不变。
