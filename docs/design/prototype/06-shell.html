窗口 / 退出生命周期

标注
  1. 点红叉 = 隐藏窗口（守护在任何模式下都不动）；Dock 点图标 / activate → 窗口回来。
  2. 真退出只有托盘「退出」一条路径，确认弹窗口径分守护托管模式：
child（壳拉起的临时进程）：「退出 Mebular 将停止本机 Mebular 守护（由本 App 拉起的临时进程）。常驻服务/外部守护不受影响。」
service（launchd 常驻）/ reused（外部已跑）：「退出 Mebular 桌面壳。本机守护不由本 App 托管，退出后照常运行。」
