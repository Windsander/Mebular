# UX-2 全量 HTML 交互原型

零依赖、零构建、假数据；**双击 `index.html`（file://）即可点**，无需起服务。
对应规格：[`../config-journey-v1.md`](../config-journey-v1.md)；视觉 token 直接复用控制台契约。

## 页面

| 页 | 覆盖 |
|---|---|
| `index.html` | 总览 + 旅程图 + 推荐路线 |
| `01-onboarding.html` | 初始化：引导态（建新/加入）→ 待重启（桌面壳一键「重启守护」 / web 命令指引） |
| `02-wizard.html` | 新版三步向导：守护未就绪（日志自动展开+人话结论）/ 初始设置子态 / ②已验证 n/m 计数 / 完成态 / 跳过持久 |
| `03-connect.html` | **核心**：三态卡片（判据注脚）、未装可点（怎么装/重检/手动登记）、＋新增助手全流程（选文件/粘片段）、接入→回读→CLI 验证→重启清单→重新验证→✓已验证；场景条覆盖**检测失败 / 写入失败 / 验证失败 / 需重启未重启** |
| `04-device.html` | 邀请：生成（loading 禁用）→ 二次确认再生 → 已连收编；加入服务未启用指路 |
| `05-daily.html` | 日常入口：完成态直达控制台，设置/诊断/关于本机（plist 收编处） |
| `06-shell.html` | 壳行为标注屏：托盘分组菜单 / 关窗=隐藏 / 退出确认口径（按托管模式）/ 单实例 |

## 推荐路线

1. `01`：点「建新并重启」→ 待重启（桌面壳）；场景切到 web 看命令指引。
2. `02`：四个场景逐一切；点「跳过」看持久化提示；完成态看「进入控制台 ✦」+ 卡片折叠。
3. `03`（多停一会）：对 OpenChamber 点「接入」走完整个验证闭环；顶部场景条切四个失败路径；点「＋ 新增助手」走两步登记（选文件 / 粘片段各试一次）。
4. `04`：生成邀请 → 重新生成的二次确认。
5. `05`/`06`：日常与壳行为（标注）。
