# UX-2 全量 HTML 交互原型

零依赖、零构建、假数据；**双击 `index.html`（file://）即可点**，无需起服务。
对应规格：[`../config-journey-v1.md`](../config-journey-v1.md)；视觉 token 直接复用控制台契约。

**批注边界**（规格 §8.1）：每页顶部灰色「评审工具」条 = 评审脚手架（页面导航 + 场景切换），
不是产品界面；产品界面内零批注，判据/路径/CLI 一律收进卡片「详情」折叠。

## 页面

| 页 | 覆盖 |
|---|---|
| `index.html` | 总览 + 旅程图 + 推荐路线（评审页） |
| `01-setup.html` | **一屏引导**（核心）：星野舞台 + 里程碑轨道，永远只有一个主按钮：① 一键开始（按钮区原位展开子步骤流水：✓启动 ✓写入 ●重启恢复；失败子步骤定位+「从此处续跑」）→ ② 行级接入（「已接入 ✓」不自动翻段，点「已完成」才翻段；可回头再接）→ 已就绪 ✦（邀请不进引导，完成页提一句）；场景：写入失败·续跑 / 无已装助手 / 已设置过·直达 |
| `03-settings.html` | 设置 · AI 助手（日常操作面）：设置侧栏（常用/AI 助手/高级/诊断）+ 单列表助手管理（与引导同语言：名称+状态词+一个动作，需处理优先排序，未安装折叠底部一行）、＋新增助手、行内展开走完验证闭环；常用区含常驻运行与「重启向导」；场景条覆盖**检测失败 / 写入失败 / 验证失败 / 需重启未重启**（一行式） |
| `04-device.html` | 邀请（单动作页）：一个主按钮 → 结果（QR+令牌+复制）；重新生成收详情（二次确认）；已连收编 +「再邀请一台 ›」折叠；加入服务未启用一行指路 |
| `05-daily.html` | **控制台首屏**（日常）：纯状态——状态总览三格（守护/对端/记忆）+「需要注意」条件待办（无事不出现）+ 星图 + 对端列表；设置/关于本机不占首屏 |
| `06-shell.html` | 壳行为标注屏（评审页）：托盘分组菜单 / 关窗=隐藏 / 退出确认口径 / 单实例 |

## 推荐路线

1. `01`（多停一会）：点「一键开始」看子步骤流水 → 给 OpenChamber 点「接入」（行级已接入，**不跳走**）→ 可再接 Claude Code → 点「已完成」→「已就绪 ✦」；评审条切「写入失败·续跑」「无已装助手」「已设置过·直达」各看一眼；点完成段的回顾行可重新展开。
2. `03`：日常再管助手的场景——设置 → AI 助手 单列表；点 OpenChamber「接入」看行内闭环；评审条切四个失败场景；「＋ 新增助手」登记流；侧栏切「常用」看常驻运行与「重启向导」。
3. `04`：生成邀请（单动作）→ QR 态；「已连」看收编 + 再邀请折叠。
4. `05`：控制台首屏——正常态纯状态；评审条切「有待办」看条件待办（去处理 → 设置 · AI 助手）。
5. `06`：壳行为（标注）。
