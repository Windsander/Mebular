# UX-2 全量 HTML 交互原型

零依赖、零构建、假数据；**双击 `index.html`（file://）即可点**，无需起服务。
对应规格：[`../config-journey-v1.md`](../config-journey-v1.md)；视觉 token 直接复用控制台契约。

**批注边界**（规格 §8.1）：每页顶部灰色「评审工具」条 = 评审脚手架（页面导航 + 场景切换），
不是产品界面；产品界面内零批注，判据/路径/CLI 一律收进卡片「详情」折叠。

## 页面

| 页 | 覆盖 |
|---|---|
| `index.html` | 总览 + 旅程图 + 推荐路线（评审页） |
| `01-onboarding.html` | 初始化：引导态（建新/加入）→ 待重启（桌面壳一键「重启守护」 / 命令行指引） |
| `02-wizard.html` | 新版三步向导：守护未就绪（日志自动展开+人话结论）/ 初始设置子态 / ②「n 个助手里 m 个已接好」/ 完成态 / 跳过持久 |
| `03-connect.html` | **核心**：三态卡片（名称+状态词+一个主按钮，判据入详情）、未装可点（怎么装）、＋新增助手全流程（选文件/粘片段）、接入→验证→待生效→重新验证→已接入 ✓；场景条覆盖**检测失败 / 写入失败 / 验证失败 / 需重启未重启**（均为一行式提示 + 一个行动） |
| `04-device.html` | 邀请：生成（loading 禁用）→ 二次确认再生 → 已连收编；加入服务未启用指路 |
| `05-daily.html` | 日常入口：完成态直达控制台，设置/诊断/关于本机 |
| `06-shell.html` | 壳行为标注屏（评审页）：托盘分组菜单 / 关窗=隐藏 / 退出确认口径 / 单实例 |

## 推荐路线

1. `01`：点「建新并重启」→ 待重启（桌面壳）；评审条切到「待重启 · 命令行」看命令指引。
2. `02`：四个场景逐一切；点「跳过」看持久化提示；完成态看「进入控制台 ✦」+ 卡片折叠。
3. `03`（多停一会）：对 OpenChamber 点「接入」走完整个验证闭环；评审条切四个失败路径（全部一行式）；点「＋ 新增助手」走两步登记；展开卡片「详情」看判据与次级动作。
4. `04`：生成邀请 → 重新生成的二次确认。
5. `05`/`06`：日常与壳行为（标注）。
