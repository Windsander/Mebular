旅程图

安装 App → 首启守护自检 → 初始化（建新/加入）→ 接入助手（三态 → 接入 → 验证闭环）→ 添加设备 → 日常
               │失败               │桌面壳一键重启          │未装也可点 · 无死按钮        │随时可回向导（回想）
               └→ 诊断与日志        └→ web 命令指引          └→ ＋新增助手（长尾零发布）

推荐路线（逐屏点一遍）

  1. ① 初始化：引导态 → 点「建新并重启」→ 待重启（桌面壳=一键「重启守护」；切到 web 场景看命令指引）
  2. ② 三步向导
  3. ③ 连接助手（核心）：三态卡片、未装可点（怎么装）、OpenChamber/Hermes 判据注脚、「＋ 新增助手」全流程、接入→验证→重启→重检；右侧场景条切到四个失败路径
  4. ④ 添加设备：生成邀请 → 二次确认再生 → 已连收编
  5. ⑤ 日常入口：完成态日常（控制台为家，设置/诊断/关于本机）
  6. ⑥ 壳行为：托盘/窗口/退出确认（HTML 跑不了壳 → 标注屏）

失败路径覆盖

检测失败 / 写入失败 / 验证失败 / 需重启未重启 → 见 ③ 连接助手 顶部「场景」切换；守护启动失败 → 见 ② 向导「守护未就绪」场景（日志自动展开 + 人话结论）。
