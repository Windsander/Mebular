旅程图

安装 App → 一屏引导（一键开始·子步骤流水 → 行级接入·点「已完成」才翻段）→ 日常控制台
                 │失败定位到子步骤+续跑        │邀请不进引导（完成页提一句）
                 └────────────── 全程一屏，不分页、不读文档

推荐路线（逐屏点一遍）

  1. ① 一屏引导（核心）：「一键开始」看子步骤流水 → 行级接入（不跳走）→「已完成」→「已就绪 ✦」；评审条切「写入失败·续跑 / 无已装助手 / 已设置过·直达」
  2. ② 设置 · AI 助手（日常操作面）：单列表 + 行内闭环、＋新增助手、四个失败场景（评审条）；侧栏「常用」有常驻运行与「重启向导」
  3. ③ 添加设备：生成邀请（单动作）→ QR 态 → 已连收编
  4. ④ 控制台首屏：现有星图原样保留；新增仅叠加层（状态条 + 条件待办）；评审条切「有待办」
  5. ⑤ 壳行为：托盘/窗口/退出确认（标注屏）

失败路径覆盖

引导期：写入失败·续跑 / 无已装助手（① 屏评审条）。接入期：检测失败 / 写入失败 / 验证失败 / 需重启未重启 → 见 ② 设置 · AI 助手 评审条。
