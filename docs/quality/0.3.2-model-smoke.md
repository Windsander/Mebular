## 5. mirror 边界

- 官方 `huggingface.co` 在首次运行时不可达；随后使用**测试专用**
  `MEBULAR_MODEL_SMOKE_MODEL_BASE_URL=https://hf-mirror.com` 完成下载。
- 测试仍走产品真实的下载、大小/SHA-256 校验、staging 和原子安装流程；mirror 只替换
  下载 base URL，不替换模型字节或校验逻辑。
- 这次成功**不证明**产品默认 Hugging Face transport、默认 DNS/网络路径或 mirror 可用性；
  也不证明其他镜像、代理或离线环境。
- `MEBULAR_MODEL_SMOKE_MODEL_BASE_URL` 是 test-only 入口（`1169cd9`），不是产品配置项，
  不构成“产品支持任意镜像”的承诺。

## 6. 未覆盖项

- 产品默认 HF transport、默认网络路径、代理/离线环境和下载吞吐。
- 其他模型 pack（8B、14B、30B-A3B 等）、其他量化和其他 `contextLength`。
- 其他平台与架构：macOS arm64、Linux、Windows；不同 CPU/GPU。
- 模型质量、recall@k、遗漏率、误召回轮次率、多种子答案质量。
- 真实宿主（DSH/Hermes/OpenCode）+ 真实模型的 prompt-injection/不可信背景防护。
- 完整 MCP/Console/host 用户旅程、跨设备同步和云沉降。
- 0.2.4 直升/降级、mixed-version 并发或双向兼容。
- final release candidate SHA；本次运行的代码/构建 SHA 是 `277a838`，不是最终发布 SHA。
- 模型输出的确定性；本次计数和字符数只代表一次运行。
