## 1. How to read this matrix

- Counts are from actual runs on the integration line. Documentation-only commits follow
  the runtime runs and do not change behaviour, but every release gate must still be
  rerun on the final release candidate.
- Historical v0.3.0 results are not reused as v0.3.2 evidence. Host counts are fresh for
  this line; they are not copied from the 0.3.0 acceptance report.
- Real, fake and stub boundaries are part of the result. A green unit suite is not a real
  host, real model, real scale or upgrade result.
- **Pass** means the listed checks actually ran. **Pending** means not run or not
  completed; it must not be rendered as passed.

### 2.1 Independent rerun note

A separate full-suite rerun from this documentation worktree executed 287 suites / 3,128
tests: 285 passed, 1 skipped, 1 failed. The failure was an `ENOTEMPTY` cleanup race while
removing a temporary `memory-runtime/logs` directory in
`tests/mcp/memory-runtime-supervisor.test.mjs`; the same suite passes **35/35** when run
alone. This is a test-cleanup flake, not a documentation change and not a clean full-suite
pass. The recorded 286/3,127 result remains the integration-session result; rerun the full
gate on the final release candidate.

## 3. Real / fake / pending boundaries

| Label | What it covers here |
|---|---|
| **Real components** | Real MCP capability and graph/event log; real managed sidecar; real DSH/OpenCode host processes for their E2E checks; real temporary filesystem. |
| **Fake / stub** | DSH deterministic test model; OpenCode fake OpenAI-compatible provider and optional controller fallback; Hermes provider-through-`agent.memory_provider` stub. Fake capability is limited to isolated unit assertions. |
| **Not proven by unit/E2E** | Real-model quality, true 10k scale, cross-device/P2P sync overhead, Console UI, desktop packaging, mixed-version behaviour. |

## 5. Evidence hygiene

- No test artifact in this matrix contains tokens, keys, message bodies or a real user
  home path.
- Scale and upgrade artifacts use temporary homes and report cleanup/residual PIDs.
- The 1k benchmark is explicitly a smoke. The 10k run is explicitly incomplete. The
  historical 0.3.0 reports keep their original SHA, host/model boundaries and counts.
