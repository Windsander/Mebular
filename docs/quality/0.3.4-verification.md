# Mebular v0.3.4 verification matrix

**Status:** Release-prep candidate, 2026-11-13. The packaging dry-run passed; formal
`release/v0.3.4` publication is pending explicit confirmation.

**Scope:** Console settings IA and settings-modal redesign (#314, #315), plus the Windows/CI
reliability changes in #313, #316 and #317. The 29-tool MCP surface, graph/event/sync formats,
host adapters and stored data are unchanged. There is no migration.

## UI and compatibility checks

- Settings v2 shell: 760×720 settings / 760×680 About device, 160px desktop rail,
  horizontal tabs at 900px and below, full-screen at narrow widths.
- Six sections: General, Security, Memory, Integrations, MCP, Advanced; About device is a
  separate entry.
- Settings rows: 40/58px templates, 150/1fr/68 field grid, 27px controls, grouped panels,
  security cards, visible configured/effective/reason warnings, and three About folds.
- Responsive baselines at 1440/1024/900/390; English and Chinese copy; reduced-motion;
  settings deep links; focus return and fixed-position service menu.
- Existing public MCP tool count (29), CLI surface and data formats are unchanged.

## Known boundaries

- Desktop packages remain unsigned; macOS Gatekeeper and Windows SmartScreen confirmation
  are required. Auto-update is not included.
- This is a Console-only release. It does not add MCP tools, host adapters, model sources or
  graph/event/sync changes.
- The settings redesign is a visual/IA change; existing configuration paths and APIs remain
  compatible.
