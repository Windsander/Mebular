unit_only、`RH+RS+FM` 或 adapter identity 补格。Go 必须等 W7 外部证据补齐后重新评审。

## 5. 可运行门禁

本轮在版本 bump 后重新执行。完整 Jest 与 Hermes Python 套件在最终提交前记录实际
counts；不能运行的 W7 外部格不计入通过。

| 门禁 | 结果 |
|---|---|
| `npm run build` | 通过（architecture guard + core/memory-runtime/service/fleet tsc） |
| `npm run lint` | 通过 |
| `npm run check:i18n` | 通过（32 项检查，0 failed） |
| `npm run check:docs` | 通过（7 项检查，0 failed） |
| `npm run check:architecture` | 通过 |
| `npm run verify:release-version` | 通过（0.4.0 SSOT 一致） |
| `tests/release` Jest | 3 suites / 17 tests passed |
| Memory Runtime / MCP / Console / OpenCode plugin / DSH / Hermes Jest | 160 suites / **2226 tests passed** |
| Hermes Python（`unittest discover`） | **109 tests passed** |

> 首次全量目标套件运行暴露了 0.4.0 版本 bump 后的 sidecar handshake 上限仍是
> `0.3.x`，导致 5 个 Memory Runtime supervisor/admin/CLI/serve/inference 套件失败。
> 将 `SIDECAR_MAX_MCP_VERSION` 与 MCP supervisor 的 fallback 更新为 `0.4.x`（并同步
> 测试断言）后，同一套件全绿。这是版本准备所需的兼容区间更新，不改变 W1–W6 语义。
