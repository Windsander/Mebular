# 阶段范围（订阅自主）

- **订阅**：任何设备可自行声明/撤回任意记忆域；零门槛、热生效。
- **域公告**：任何设备可建域（`namespace_declare`）；建域零门槛；**不做「删除域」**（域是全网共享公告、无主；全网删域属未来治理协议）。
- **移出**：`device_revoke` 作者级否定；不连坐后代；UI 称「移出」。
- **恢复**：`device_restore` + 恢复纪元 E-1；恢复后需重新订阅；low/medium 无额外门槛，high 需会签/恢复码。
- **退出并交接**：退订 + 本机清理数据/水位 + `namespace_handoff` 审计；需继任者 ack。
- **安全档**：low/medium/high 只作用于加入/邀请/移出/改档；建域与订阅永远零门槛。

**已删除**：grant/revoke/issuer/自动签发/对端×按域白名单/链级连坐/R-d 恢复授权。
